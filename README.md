# DMGOTRAVEL FRONTEND

Frontend independiente de **DMGOTRAVEL**, orientado a experiencias turísticas del Perú con énfasis visual en la región de **Ayacucho**.

## Stack
- React + TypeScript + Vite
- TanStack Router
- TanStack Query
- Tailwind CSS
- shadcn/ui

## Estado
Este repositorio contiene el avance importado desde Lovable y se está estabilizando de forma independiente al repositorio principal.

## Desarrollo local

```bash
bun install
bun run dev
```

## Validación

```bash
bunx tsc --noEmit
bun run build
```
